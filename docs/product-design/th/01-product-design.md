# 01. Product design

## 1. ปัญหาที่แก้

นักศึกษาสายสุขภาพปี 1–2 ต้องจำกระดูก จุดสังเกต (landmark) และจุดเกาะกล้ามเนื้อจำนวนมาก แล้วไปสอบ spot ที่ต้องตอบชื่อจากชิ้นจริงภายในเวลาจำกัด แอป 3D ที่มีอยู่ส่วนใหญ่ไม่มีภาษาไทย และไม่ได้ลงรายละเอียดถึงระดับ landmark ที่ใช้สอบ (ดู [แผน product ปีแรก](../product-plan/index.html))

แอปนี้จึงตั้งใจทำ 3 อย่างให้ดีที่สุด:

1. ดูกระดูก 3D พร้อมชื่อไทย อังกฤษ และละติน ในทุกจุดที่มีชื่อ
2. เห็น landmark และจุดเกาะกล้ามเนื้อบนผิวกระดูกในระดับที่ใช้สอบจริง
3. ฝึกสอบ spot แบบจับเวลาบนโมเดล 3D แล้วทบทวนจุดที่ตอบผิดต่อบนมือถือ

## 2. ผู้ใช้

แอปออกแบบให้**นักศึกษาแพทย์และบุคลากรด้านสุขภาพ** ซึ่งต้องการรายละเอียดมากที่สุด ผู้ใช้ไม่ต้องเลือกบทบาทหรือวิชาชีพ ทุกคนเห็นเนื้อหาชุดเดียวกันในระดับละเอียดที่สุด (Jedt ตัดสินใจ 27 พ.ย. 2026) โหมดสำหรับศิลปินจะทำในภายหลัง

จุดคลินิกจึงเป็นชุดเดียวที่ผูกกับ landmark ทุกจุด แบ่งเป็น 4 หมวดในหน้าจุดคลินิก:

| หมวด | ตัวอย่าง |
|---|---|
| กระดูกหัก | ตำแหน่งที่หักบ่อย และเส้นประสาทหรือหลอดเลือดที่เสี่ยง |
| ฟัน · รูเปิด | ฟันแท้และเลข FDI รูเปิดของกะโหลกและสิ่งที่ผ่าน |
| ฉีดยา | ventrogluteal, deltoid, vastus lateralis หาตำแหน่งจาก landmark |
| จุดคลำ | landmark ที่คลำได้บนผิวกาย |

ผู้เริ่มเรียนไม่ต้องตั้งค่าอะไรเพิ่ม หน้าจอเปิดจากชื่อกระดูกก่อน แล้วค่อยลงไปที่ landmark และจุดคลินิกในหน้าเดียวกัน

ผู้ใช้กลุ่มที่สองคือ **อาจารย์** ที่สร้างชุด spot ของตัวเองแล้วแชร์รหัสให้นักศึกษา (โหมดอาจารย์) และตรวจรายการแจ้งแก้ที่เป็นเนื้อหา

## 3. หลักการออกแบบ

1. **ภาษาไทยมาก่อน แต่ไม่ทิ้งศัพท์สากล** ทุกชื่อแสดงเป็นชุด ไทย / EN / LA ลำดับเปลี่ยนได้ตามที่ผู้ใช้ตั้ง เพราะข้อสอบและตำราใช้ทั้งสามภาษา
2. **โมเดลอยู่ตรงกลางเสมอ** หน้าจอเรียนทุกหน้าใช้ viewport 3D เป็นพื้นที่หลัก ข้อมูลอยู่ในแผงด้านข้าง ไม่บังโมเดล
3. **รู้สึกเหมือนแอปของ iPad** ใช้ widget Cupertino และสี systemBlue ตาม iOS ผู้ใช้ไม่ต้องเรียนรู้วิธีใช้ใหม่
4. **แจ้งแก้ได้ในสองแตะจากทุกที่** ทุก label และทุกข้อสอบมีปุ่มแจ้งแก้ ระบบแนบชิ้นส่วนและมุมกล้องให้เอง และผู้แจ้งเห็นสถานะจนแก้เสร็จ
5. **ใช้ได้โดยไม่มีเน็ต** iPad โหลดแพ็กเนื้อหาไว้ใช้ offline ได้ เพราะห้องเรียนและหอพักหลายแห่งเน็ตไม่นิ่ง
6. **ซื่อตรงเรื่องฟรีและ Pro** ปีแรกฟรีทั้งหมด และบอกตั้งแต่วันแรกว่าหลังเปิดขายอะไรจะเป็น Pro

## 4. บทบาทของแต่ละแพลตฟอร์ม

| แพลตฟอร์ม | บทบาท | สิ่งที่ทำได้ | สิ่งที่ตั้งใจไม่ทำ |
|---|---|---|---|
| **iPad** (หลัก) | เรียนกับโมเดลและฝึกสอบ | ทุก feature, offline, โหมดอาจารย์ | |
| **มือถือ** (companion) | ทบทวนช่วงเวลาสั้น ๆ | flashcard แบบ spaced repetition, โน้ตสั้น, ค้นศัพท์ offline, ภาพนิ่งพร้อมหมุด | viewer 3D เต็ม, ฝึกสอบ spot แบบจับเวลา |
| **เว็บ** | อ่านฟรีและให้ค้นเจอ | หน้าอ่าน HTML ทุกกระดูก (SEO), viewer 3D ด้วย Flutter Web | offline, จุดคลินิกเต็ม |

## 5. โครงสร้างแอป (information architecture)

### iPad: tab bar 5 แท็บ

| แท็บ | หน้าแรก | ไปต่อได้ที่ |
|---|---|---|
| หน้าหลัก | เรียนต่อจากครั้งก่อน, เลือกส่วนร่างกาย, spot วันนี้ | viewer, คลัง, ฝึกสอบ |
| คลังกระดูก | รายการกระดูกแบบ split view ตามส่วนร่างกาย และ A–Z | ค้นหา, viewer |
| ฝึกสอบ | ตั้งค่าชุด spot | คำถาม → เฉลย → ผลสอบ, โหมดอาจารย์ |
| โน้ต | โน้ตและ bookmark | เปิดมุมกล้องที่บันทึกไว้ใน viewer |
| ฉัน | โปรไฟล์ การตั้งค่า สิทธิ์ beta | รายการที่ฉันแจ้ง, ข้อมูล offline |

viewer 3D เป็นหน้าเต็มจอที่เปิดจากแท็บใดก็ได้ มี segmented control สลับโหมด **กระดูก / จุดสังเกต / จุดเกาะกล้ามเนื้อ / จุดคลินิก**

### มือถือ: tab bar 4 แท็บ
ทบทวน · โน้ต · ค้นหา · ฉัน

### เว็บ
ดัชนี (ส่วนร่างกาย + A–Z) → หน้าอ่านของแต่ละกระดูก → viewer 3D บนเว็บ

## 6. Flow หลัก

1. **เริ่มใช้ครั้งแรก:** ยินดีต้อนรับ → เลือกลำดับภาษาและความยินยอม beta (แยก analytics กับการติดต่อกลับ ตาม PDPA) → หน้าหลัก
2. **เรียน:** หน้าหลักหรือคลัง → viewer โครงกระดูก → แตะกระดูก → landmark / จุดเกาะ / จุดคลินิก → แจ้งแก้ได้ทุกจุด
3. **ฝึกสอบ spot:** ตั้งค่า (ส่วนร่างกาย จำนวนข้อ เวลา ประเภทคำถาม) → คำถามจับเวลา → เฉลยพร้อมชื่อ 3 ภาษา → ผลสอบและจุดอ่อน → ทบทวนข้อผิดหรือสอบใหม่
4. **ทบทวนบนมือถือ:** ข้อที่ตอบผิดและโน้ตที่เปิด "ทำเป็น flashcard" กลายเป็นการ์ด → ทบทวนวันนี้ → ให้คะแนน ลืม / ยาก / ดี / ง่าย
5. **วงจรแจ้งแก้:** แตะแจ้งแก้ → เลือกเรื่อง → ส่ง → ติดตามสถานะในหน้า "รายการที่ฉันแจ้ง" → ได้รับแจ้งเมื่อแก้แล้ว นับเป็นสิทธิ์ผู้ทดสอบ beta

## 7. สิ่งที่ไม่ทำในปีแรก
ตามแผน product: อวัยวะภายใน หลอดเลือดและเส้นประสาทแบบ 3D กล้ามเนื้อขาและลำตัว AR/VR AI chat แอป Android แบบ native (ใช้เว็บแทน) ฟันน้ำนม
