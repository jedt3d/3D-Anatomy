# 02. Requirements

ตัวเลขที่มีป้าย **(ประมาณการ)** ยังไม่ได้วัดจริง ต้องยืนยันใน spike เดือนที่ 1 หรือกับคณะพาร์ตเนอร์ หน้าจอที่อ้างถึงคือชื่อ frame ในไฟล์ Figma

## 1. Functional requirements

### Viewer 3D
| ID | Requirement | เกณฑ์ยอมรับ | หน้าจอ |
|---|---|---|---|
| FR-01 | หมุน ซูม เลื่อนโมเดล และแตะเลือกกระดูก | แตะแล้วกระดูกที่เลือก highlight และแผงข้อมูลเปลี่ยนภายใน 100 ms **(ประมาณการ)** | iPad/20 |
| FR-02 | Isolate, ซ่อน, x-ray, แยกชิ้น, รีเซ็ตมุมกล้อง | ทุกปุ่มอยู่ในแถบเครื่องมือด้านซ้าย สถานะเปิดแสดงเป็นปุ่มสีน้ำเงิน | iPad/20–24 |
| FR-03 | สลับโหมด กระดูก / จุดสังเกต / จุดเกาะกล้ามเนื้อ / จุดคลินิก | โหมดอยู่ใน segmented control บนสุดของ viewport | iPad/20–24 |
| FR-04 | แสดงชื่อกระดูกและข้างของร่างกาย (ซ้าย/ขวา) | ป้ายบอกข้างแสดงทุกครั้งที่เลือกกระดูกคู่ | iPad/20 |

### ชื่อและเนื้อหา
| ID | Requirement | เกณฑ์ยอมรับ | หน้าจอ |
|---|---|---|---|
| FR-10 | ทุกชื่อแสดงเป็น ไทย / EN / LA | ใช้ widget NameTriple ทุกจุด ลำดับตามการตั้งค่า | ทุกหน้า |
| FR-11 | อ่านออกเสียงศัพท์อังกฤษและละติน | ปุ่มลำโพงข้างชื่อ เล่นได้ offline เมื่อโหลดแพ็กเสียงแล้ว | iPad/21, Phone/03 |
| FR-12 | Landmark: หมุดบนโมเดลและรายการในแผง | แตะหมุดหรือแถวในรายการแล้วเลือกตรงกัน, ระบุ "คลำได้" ถ้าคลำได้ | iPad/21 |
| FR-13 | แผนที่จุดเกาะ origin / insertion | origin สีแดง insertion สีน้ำเงิน มีชื่อกล้ามเนื้อ การกระทำ เส้นประสาท | iPad/22 |
| FR-14 | กะโหลกแยกชิ้นและฟันแท้ FDI | slider แยกชิ้น, ผังฟัน 32 ซี่ แตะเลข FDI แล้วเลือกฟันบนโมเดล | iPad/23 |
| FR-15 | จุดคลินิกตามเลนส์ | แสดงขั้นตอนหาตำแหน่งจาก landmark และคำเตือนตำแหน่งเสี่ยง พร้อมข้อความว่าใช้เพื่อการเรียน | iPad/24 |
| FR-16 | ค้นหาไทย / อังกฤษ / ละติน แบบ offline | พิมพ์บางส่วนก็เจอ ผลแยกตามกระดูก landmark กล้ามเนื้อ จุดคลินิก | iPad/12, Phone/05 |

### ฝึกสอบ spot
| ID | Requirement | เกณฑ์ยอมรับ | หน้าจอ |
|---|---|---|---|
| FR-20 | ตั้งค่าชุด spot | เลือกส่วนร่างกาย ประเภทคำถาม (ชื่อ / ข้าง / สิ่งที่มาเกาะ) จำนวนข้อ เวลาต่อข้อ ภาษาที่ยอมรับ | iPad/30 |
| FR-21 | คำถามจับเวลาบนโมเดล 3D | หมุดคำถามปักบนโมเดล นับถอยหลังต่อข้อ หมุนโมเดลได้แต่ซ่อนชื่อทั้งหมด | iPad/31 |
| FR-22 | ตรวจคำตอบ | รับคำตอบได้ทั้งสามภาษาและคำพ้อง สะกดผิดเล็กน้อยได้คะแนนพร้อมคำเตือน **(ต้องยืนยันกติกากับคณะ)** | iPad/32 |
| FR-23 | สรุปผลและจุดอ่อน | คะแนน เวลา ข้อผิดแยกตามหัวข้อ ปุ่มทบทวนข้อผิดและสอบใหม่ ส่งข้อผิดเป็น flashcard | iPad/33 |
| FR-24 | โหมดอาจารย์ | ปักหมุดเอง ตั้งเวลา ได้รหัสแชร์สั้น (เช่น K7Q-2MX) นักศึกษาเปิดด้วยรหัสได้ | iPad/34 |

### แจ้งแก้และ feedback

|---|---|---|---|

| FR-32 | แจ้งกลับเมื่อแก้แล้ว | แจ้งในแอป และทาง LINE ถ้าผู้ใช้เปิดไว้ | iPad/41 |

## 2. Non-functional requirements

| ID | หัวข้อ | Requirement |
|---|---|---|
| NFR-01 | ประสิทธิภาพ | viewer เปิดแพ็กหนึ่งส่วนร่างกายภายใน 3 วินาที และหมุนได้ 60 fps บน iPad รุ่นพื้นฐาน **(ประมาณการ ต้องวัดใน spike)** |
| NFR-02 | ขนาดดาวน์โหลด | แพ็กละไม่เกิน 150 MB ใช้ meshopt และ KTX2 ตามไปป์ไลน์ 3D **(ประมาณการ)** |
| NFR-03 | Offline | ทุก feature ยกเว้นซิงก์โน้ตและส่งแจ้งแก้ ใช้ได้โดยไม่มีเน็ตเมื่อโหลดแพ็กแล้ว |
| NFR-04 | การเข้าถึง | ข้อความเนื้อหา contrast ≥ 4.5 : 1, เป้าแตะ ≥ 44 × 44 pt, รองรับ Dynamic Type และ Increase Contrast |
| NFR-05 | ภาษา | UI ภาษาไทยเป็นหลัก ศัพท์กายวิภาคแสดงสามภาษา ระยะบรรทัดภาษาไทยประมาณ 1.4 เท่าเพื่อไม่ให้สระบนล่างโดนตัด |
| NFR-06 | PDPA | ขอความยินยอมแยก analytics กับการติดต่อกลับ, รองรับผู้ใช้อายุต่ำกว่า 20, ลบบัญชีได้เอง (ให้ที่ปรึกษากฎหมายตรวจก่อนเปิด beta) |
| NFR-07 | Analytics | เก็บเฉพาะเหตุการณ์ที่ใช้ตัดสินใจ (เปิดแพ็ก ทำ spot ตอบผิดตรงไหน แจ้งแก้) ไม่เก็บข้อมูลอ่อนไหว |
| NFR-08 | ความถูกต้องของเนื้อหา | เนื้อหาทุกชิ้นมีวันที่ตรวจและผู้ตรวจ แก้ใน content DB ได้โดยไม่ต้องออก build ใหม่ |
| NFR-09 | ความสอดคล้องข้ามแพลตฟอร์ม | iPad มือถือ เว็บ ใช้ token และ widget ชุดเดียว (Flutter) หน้าอ่าน HTML ใช้ token สีและตัวอักษรเดียวกัน |
| NFR-10 | Dark mode | ทุกสีมีค่า Light และ Dark ผ่าน CupertinoDynamicColor viewport มืดเสมอ |
