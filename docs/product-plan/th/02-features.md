# 02. Feature, จุดแข็ง, จุดอ่อน และจุดขาย

## 1. Feature ที่ต้องมี (must-have ใน v1.0)

ผู้ใช้ทุกคนคือนักศึกษาแพทย์หรือบุคลากรทางการแพทย์ แอปไม่มีขั้นตอนเลือกบทบาท และเปิดมาเจอเนื้อหาระดับละเอียดที่สุดทันที

| # | Feature | ใช้ตอนไหน | ทำไมต้องมี |
|---|---|---|---|
| 1 | **Viewer 3D**: หมุน ซูม แตะเลือกชิ้น, isolate, ซ่อน, x-ray, แยกชิ้นกะโหลก (exploded view) | ทุกครั้ง | พื้นฐานที่ทุกแอปมี ไม่มีไม่ได้ ใช้ฟีเจอร์ที่ผ่าน spike แล้ว |
| 2 | **ชื่อ 3 ภาษา ไทย / อังกฤษ / ละติน** สลับได้ทุกจุด พร้อมเสียงอ่านออกเสียงศัพท์อังกฤษ/ละติน (อัดเสียงเอง) | ทุกครั้ง โดยเฉพาะปีแรกของกายวิภาค | ช่องว่างหลักจากรายงานตลาด: แอปรายใหญ่ไม่มีไทย และ Anatomyka / 3D Anatomy ใน App Store ไทยก็ไม่มีไทยในรายการภาษา [S8][S9] |
| 3 | **Landmarks**: แตะกระดูก เห็นหมุดจุดสังเกตทั้งหมด แตะหมุดเห็นคำอธิบายสั้นและสิ่งที่มาเกาะ | เรียนและทบทวน | ระดับรายละเอียดที่ใช้สอบจริง ต่างจากแอปที่ label แค่ชื่อกระดูก |
| 4 | **แผนที่จุดเกาะกล้ามเนื้อ** บนผิวกระดูก (origin/insertion) พร้อมชื่อกล้ามเนื้อ การกระทำ เส้นประสาท | เรียนและทบทวน | ได้เนื้อหากล้ามเนื้อโดยไม่ต้องปั้นกล้ามเนื้อ (ดู [01-scope](01-scope.md)) |
| 5 | **โหมดฝึกสอบ spot**: หมุดปักบนโมเดล 3D ถามชื่อ/ด้าน/สิ่งที่เกาะ จับเวลาต่อข้อ สรุปคะแนนและจุดที่พลาด | ช่วงสอบ | จำลองการสอบปฏิบัติการกายวิภาค **(ประมาณการ: ต้องยืนยันรูปแบบสอบจริงกับคณะพาร์ตเนอร์)** |
| 6 | **ค้นหา 3 ภาษา** พิมพ์ไทย อังกฤษ หรือละติน แล้วกระโดดไปที่ชิ้นส่วนหรือ landmark บนโมเดล | ทุกครั้ง | นักศึกษาเจอศัพท์ในชีทเป็นภาษาหนึ่งและต้องหาตำแหน่งบนโมเดลให้เร็ว |
| 7 | **ความสัมพันธ์ทางคลินิก** ติดกับแต่ละ landmark (ชุดเดียวสำหรับทุกคน): กระดูกหักที่พบบ่อยและเส้นประสาทที่เสี่ยง, จุดคลำ, ตำแหน่งฉีดยาเข้ากล้าม, รูเปิดของกะโหลกและสิ่งที่ผ่าน, ฟันและเลข FDI | เรียนและทำงาน | เชื่อมกระดูกกับงานจริงในระดับที่นักศึกษาแพทย์และแพทย์จบใหม่ใช้ คู่แข่งทั่วไปไม่ได้ทำเป็นภาษาไทย |
| 8 | **ใช้ offline บน iPad**: ดาวน์โหลดเป็นแพ็กตามส่วนร่างกาย ตรวจ hash อัปเดตเฉพาะแพ็กที่เปลี่ยน | เรียนนอกห้อง | Anatomy Learning พิสูจน์แล้วว่า offline + ราคาถูกขายได้ (รายงานตลาด) |
| 9 | **เว็บอ่านฟรี**: ทุกกระดูกและ landmark มีหน้าเว็บภาษาไทย (Flutter Web สำหรับ 3D + หน้า HTML ธรรมดาสำหรับอ่านและให้ Google ค้นเจอ) | ก่อนติดตั้งแอป | ช่องทางหาผู้ใช้ฟรี และตอบโจทย์ "ต้องได้อ่านฟรี" |
| 10 | **ปุ่ม "แจ้งแก้" ทุก label และทุกข้อสอบ** (ศัพท์ไทยผิด, ตำแหน่งผิด, อยากได้เพิ่ม) พร้อมสถานะว่าแก้แล้วหรือยัง | ทุกครั้ง | กลไก feedback หลัก (ดู [03](03-free-and-feedback.md)) |

### ควรมี (should-have ถ้าทันในปีแรก)
- โมดูลกล้ามเนื้อแขน 3D (~50 มัด) ซ้อนบนกระดูก
- โน้ตส่วนตัวและ bookmark ที่ซิงก์ระหว่าง iPad กับเว็บ
- แอปมือถือเล็กสำหรับทบทวน (flashcard จาก content DB ไม่มี 3D) ตามแนวคิด companion app ในหัวข้อโครงการ
- โหมดอาจารย์: สร้างชุด spot ของตัวเองแล้วแชร์ลิงก์ให้นักศึกษา

### ไม่ทำในปีแรก
AI chat, AR, VR, แบบจำลองการเคลื่อนไหวข้อต่อ, ภาพ CT/MRI

## 2. จุดแข็ง (ของ product และทีม)
1. **ภาษาไทยที่อาจารย์ไทยตรวจ** ยังไม่พบคู่แข่ง 3D กายวิภาคการแพทย์ที่รองรับไทย (รายงานตลาด และ [S8][S9])
2. **เป็นเจ้าของ asset 100%** เพราะปั้นเองทั้งหมด: ไม่มีค่า license รายปี, ขาย license ให้คณะได้, ทำต่อเป็น SKU ศิลปินหรือภาษาอื่นได้โดยไม่ต้องขออนุญาตใคร
3. **ลึกในพื้นที่แคบ ระดับนักศึกษาแพทย์**: landmarks และจุดเกาะละเอียดกว่าแอปทั่วไปที่ label แค่ชื่อกระดูก และไม่ต้องแบ่งเนื้อหาหลายระดับ จึงทำทีมเล็กได้
4. **ใกล้ผู้ใช้**: อยู่ในไทย เข้าถึงคณะ อาจารย์ และนักศึกษาได้โดยตรง แก้ตาม feedback ได้ทุกเดือน
5. **ฐานเทคนิคเดียว** Flutter ทุกแพลตฟอร์ม: iPad ก่อน เว็บได้ทันที Android ตามมาโดยไม่ต้องเขียนใหม่
6. **ราคาเข้าถึงได้** ตั้งเป้าประมาณ 1/5 ของเจ้าใหญ่ (Complete Anatomy นักศึกษา $74.99/ปี จากรายงานตลาด)

## 3. จุดอ่อน และวิธีรับมือ

| จุดอ่อน | ผลกระทบ | วิธีรับมือ |
|---|---|---|
| เนื้อหาน้อยกว่าเจ้าใหญ่มาก (Complete Anatomy 700+ โมเดล) | ผู้ใช้ที่อยากได้ทั้งตัวจะไม่เลือกเรา | สื่อสารชัดว่า "เครื่องมือสอบกระดูกภาษาไทยที่ดีที่สุด" ไม่ใช่ "atlas ทั้งตัว" และใช้คู่กับแอปอื่นได้ |
| กระดูก 3D ฟรีมีอยู่แล้ว (Anatomyka) [S8] | ต้องมีเหตุผลอื่นให้เลือกเรา | จุดขายคือภาษาไทย, landmarks, spot, ความสัมพันธ์ทางคลินิก ไม่ใช่โมเดล |
| กำลัง artist เป็นคอขวด | ปั้นช้าแผนเลื่อน | ปั้นตามลำดับหลักสูตร, ปล่อยทีละแพ็ก, วัดเวลาจริงหลัง 3 ชิ้นแรก |
| ความถูกต้องทางกายวิภาค | ผิดครั้งเดียวเสียความน่าเชื่อถือ | บอร์ดอาจารย์ตรวจก่อนปล่อยทุกแพ็ก, ปุ่มแจ้งแก้, บันทึกการแก้แบบเปิดเผย |
| flutter_scene ยังไม่มีใครใช้ทำแอปกายวิภาค | อาจต้องเปลี่ยน renderer | spike 2 สัปดาห์เดือนแรก, three.js เป็นแผนสำรอง, asset ไม่ต้องเปลี่ยน |
| ตลาดไทยเล็กและจ่ายน้อย | รายได้ปีแรกต่ำ | ปีแรกวัดผลด้วยการใช้งานไม่ใช่รายได้, เตรียมขาย license ให้คณะ, ต่อยอด VN/ID ปีที่ 2 |
| เนื้อหาระดับนักศึกษาแพทย์อาจหนักเกินไปสำหรับผู้เริ่มเรียนหรือสายสุขภาพอื่น | บางคนเลิกใช้เร็ว | เรียงจากชื่อชิ้นไปหา landmark ทีละชั้นในหน้าจอเดียวกัน (ไม่แยกโหมด) และดูข้อมูลใน alpha ว่าใครหลุดตรงไหน |
| ผู้ใช้ฟรีอาจไม่ยอมจ่าย | conversion ต่ำ | บอกตั้งแต่แรกว่าอะไรฟรีตลอด อะไรจะเป็นแบบจ่าย และให้สิทธิ์ผู้ร่วมทดสอบ (ดู [03](03-free-and-feedback.md)) |

## 4. จุดขายที่ต้องทำให้ได้ (selling points)
เรียงตามความสำคัญ แต่ละข้อมีวิธีพิสูจน์:

1. **"กายวิภาคกระดูก 3D ภาษาไทย ที่อาจารย์ไทยตรวจ"** พิสูจน์ด้วยรายชื่ออาจารย์ผู้ตรวจในแอป (ได้รับอนุญาตแล้ว)
2. **"ฝึกสอบ spot ได้ทุกที่ แม้ไม่มีเน็ต"** พิสูจน์ด้วยคะแนนก่อน/หลังของกลุ่มพาร์ตเนอร์ (ถ้าคณะยอมทำวิจัยร่วม)
3. **"ละเอียดพอสำหรับสอบแพทย์ และใช้ต่อได้ตอนทำงาน"** พิสูจน์ด้วยจำนวน landmarks และความสัมพันธ์ทางคลินิกที่อาจารย์ตรวจแล้ว
4. **"อ่านฟรีบนเว็บ ทุกกระดูก"** พิสูจน์ด้วยการไม่มี paywall บนหน้าอ่าน
5. **"ราคานักศึกษาไทย"** ตั้งราคาหลังเดือนที่ 12 จากข้อมูล willingness-to-pay ที่เก็บระหว่างปี
