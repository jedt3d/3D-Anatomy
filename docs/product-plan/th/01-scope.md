# 01. Scope: niche ที่แคบที่สุดที่ทำจบได้ใน 1 ปี

## 1. เงื่อนไขที่บังคับ scope
1. **ปั้นเองทั้งหมด** ทั้ง mesh และ texture ไม่ใช้โมเดล Creative Commons หรือโมเดลที่ซื้อ license มา ดังนั้นตัวจำกัดจริงคือ **จำนวนวันทำงานของ 3D artist** ไม่ใช่โค้ด
2. **กลุ่มเป้าหมาย 4 วิชาชีพ** แพทย์ ทันตะ พยาบาล เภสัช (นักศึกษาและคนทำงานช่วงแรก) ต้องเจอส่วนที่ตัวเองใช้
3. **1 ปี** ต้องมีเวอร์ชันที่ใช้ได้จริงในมือนักศึกษาเร็ว (ไม่เกินเดือนที่ 3) เพราะ feedback คือหัวใจ
4. ต่อจาก pipeline ที่ตัดสินแล้ว: Flutter + flutter_scene, GLB, Blender เป็นศูนย์กลาง, LightWave/3D-Coat สำหรับปั้น ([ไปป์ไลน์ 3D](../3d-pipeline/index.html))

## 2. ตัวเลือกที่พิจารณา

| ตัวเลือก | งานปั้น (ประมาณการ) | ครอบคลุม 4 วิชาชีพ | ความเสี่ยงถูก/ผิด | ผล |
|---|---|---|---|---|
| A. ทั้งตัวทุกระบบแบบหยาบ | มากมาก (อวัยวะ กล้ามเนื้อ หลอดเลือด เส้นประสาท) | ครบแต่ตื้น | สูง | ตัดทิ้ง: แข่งกับ Complete Anatomy ที่มี 700+ โมเดลไม่ได้ |
| B. ศีรษะและลำคอ (เน้นทันตะ) | มาก: เส้นประสาทสมอง กล้ามเนื้อหน้า หลอดเลือดซับซ้อน | ทันตะ + แพทย์ | สูง | เก็บไว้ปีที่ 2 |
| C. กล้ามเนื้อทั้งตัว | ~600 มัด และต้องแก้ทับซ้อนกับกระดูก | แพทย์ + PT | กลาง | เกินกำลังปีแรก |
| **D. โครงกระดูก + landmarks + จุดเกาะกล้ามเนื้อ + กะโหลกและฟัน** | **~120 mesh + ฟัน 16 ซี่** | **ทั้ง 4** | **ต่ำ-กลาง** | **เลือก** |

### เหตุผลที่เลือก D
- **ทุกวิชาชีพเรียนกระดูก** และจุดสังเกตบนกระดูกเป็นฐานของเรื่องที่แต่ละวิชาชีพใช้ทางคลินิก: ตำแหน่งฉีดยาเข้ากล้าม (พยาบาล เภสัช), กะโหลก รูเปิด และฟัน (ทันตะ), ตำแหน่งกระดูกหักและจุดคลำ (แพทย์)
- **กระดูกปั้นง่ายที่สุด** เป็นวัตถุแข็ง ไม่ต้อง rig ไม่ต้องทำ blend shape และ texture ใช้ชุด material กระดูกร่วมกันได้
- **จุดเกาะกล้ามเนื้อเป็นแค่ texture/mask บนกระดูก** (origin สีหนึ่ง insertion อีกสีหนึ่ง) จึงสอนเรื่องกล้ามเนื้อได้ก่อนจะปั้นกล้ามเนื้อจริง
- **ตรงกับ spike ที่วางไว้แล้ว** (โครงกระดูก + กล้ามเนื้อแขน ~200–400 ชิ้น) ใน [01-pipeline หัวข้อ 7](../3d-pipeline/pipeline.html) งาน spike จึงกลายเป็นเนื้อหาจริงชิ้นแรก
- **ใช้ต่อกับ SKU ศิลปิน** ในอนาคตได้ (โครงกระดูกและกล้ามเนื้อแขนขาเป็นสิ่งที่ศิลปินต้องใช้ด้วย) ตามข้อสรุปรายงานตลาดว่า Med + Artist ใช้ engine เดียว

### ข้อควรรู้: กระดูกฟรีมีอยู่แล้ว
Anatomyka ใน App Store ไทยให้ใช้ระบบโครงกระดูกฟรี และเก็บเงินระบบอื่น (รายปี ฿999, Pro ฿2,490, lifetime ฿5,990) แต่รายการภาษาในร้านมีแค่ภาษาอังกฤษ [S8] ดังนั้น **"มีโมเดลกระดูก 3D" ไม่ใช่จุดขาย** จุดขายต้องมาจากภาษาไทยที่ตรวจแล้ว, landmarks ละเอียดแบบที่ใช้สอบ, โหมดฝึกสอบ spot และเลนส์วิชาชีพ (ดู [02-features](02-features.md))

## 3. ขอบเขตงานปั้น 3D (asset scope)

ทุกตัวเลขในตารางนี้เป็น **(ประมาณการ)** ของเรา ต้องวัดจริงหลังปั้นกระดูก 3 ชิ้นแรก (femur, scapula, vertebra) แล้วปรับ

| กลุ่ม | จำนวน mesh ที่ไม่ซ้ำ | วัน artist ต่อชิ้น | รวมวัน | หมายเหตุ |
|---|---|---|---|---|
| กระดูกแขน (รวมมือ) | ~32 | 0.5–3 | ~35 | ชุดแรก ใช้ทำ spike |
| กระดูกขาและเชิงกราน (รวมเท้า) | ~31 | 0.5–3 | ~35 | |
| กระดูกสันหลัง กระดูกเชิงกรานแกนกลาง ซี่โครง กระดูกอก | ~40 | 1–1.5 | ~50 | สันหลังแต่ละระดับต่างกัน ต้องปั้นแยก |
| กะโหลก (แยกชิ้น) + hyoid + กระดูกหู | ~22 | 1–5 | ~45 | ชิ้นที่ยากที่สุด: sphenoid, temporal, ethmoid |
| ฟันแท้ (mirror ซ้าย/ขวา) | 16 | 1–1.5 | ~20 | ใช้เลข FDI จุดดึงทันตะ |
| Texture: material กระดูกร่วม + mask จุดเกาะกล้ามเนื้อ | ทุกชิ้น | - | ~60 | วาดเอง ไม่ใช้ texture สำเร็จรูป |
| ตรวจแก้หลังอาจารย์รีวิว | - | - | ~40 | สำรองไว้ ~15% |
| **รวม must-have** | **~140** | | **~285** | |
| กล้ามเนื้อแขน (should-have ปลายปี) | ~50 มัด | ~2 | ~100 | ต้องปั้นให้พอดีกับกระดูก |
| **รวมทั้งปี** | | | **~385** | artist 2 คน × ~200 วันทำงาน = ~400 วัน |

### reference โดยไม่ใช้โมเดลคนอื่น
- **กระดูกแห้งของคณะพาร์ตเนอร์** ถ่ายภาพหรือ photogrammetry ด้วยทีมเราเองเพื่อใช้เป็น reference (ไม่ใช่ mesh สุดท้าย) ต้องได้รับอนุญาตเป็นลายลักษณ์อักษรจากภาควิชา และเคารพธรรมเนียมเรื่องร่างอาจารย์ใหญ่
- **ตำรา atlas และภาพถ่าย** ใช้ดูเป็น reference เท่านั้น ไม่ trace หรือคัดลอกภาพ
- ข้อมูล CT หรือสแกนจากฐานข้อมูลเปิด **ไม่ใช้** เพราะเงื่อนไข license หลายชุดเป็นแบบ Creative Commons ซึ่งขัดกับนโยบาย

## 4. ข้อมูลเนื้อหา (content DB) ที่ต้องทำคู่กัน
3D เป็นแค่ครึ่งเดียว ตาม [ไปป์ไลน์ 3D หัวข้อ 5](../3d-pipeline/pipeline.html) GLB เก็บแค่ geometry กับ ID ส่วนสิ่งที่คนอ่านอยู่ใน content DB:
- ชื่อ 3 ภาษา: ไทย / อังกฤษ / ละติน (Terminologia Anatomica 2) ใช้ศัพท์ไทยตามที่อาจารย์ไทยใช้สอนจริง ถ้าศัพท์ไม่ตรงกันระหว่างคณะ เก็บทุกแบบพร้อมระบุแหล่ง
- landmarks **(ประมาณการ)** ~800–1,200 จุดในปีแรก เทียบ Anatomy Learning ที่มี 6,000+ จุดทั้งตัว (จากรายงานตลาด)
- จุดเกาะกล้ามเนื้อ, การกระทำ, เส้นประสาทที่ควบคุม (ข้อความ ไม่ต้องมี 3D ของเส้นประสาท)
- หมายเหตุคลินิกตามวิชาชีพ, ข้อสอบ spot
- **ต้องมีคนรับผิดชอบเต็มเวลา 1 คน** (นักกายวิภาคหรือแพทย์จบใหม่ที่สนใจการสอน) เพราะนี่คือ moat จริงตามบทเรียนของ BioDigital

## 5. กำลังคนที่สมมติ (ประมาณการ)

| บทบาท | คน | หน้าที่ |
|---|---|---|
| 3D artist | 2 | ปั้น, retopo, UV, bake, texture ตาม pipeline |
| Content lead (กายวิภาค) | 1 | content DB, landmarks, ข้อสอบ, ประสานอาจารย์ |
| Flutter developer | 2 | แอป iPad + เว็บ, ระบบ pack offline, feedback, analytics |
| Product/UX + community | 1 (Jedt) | ทิศทาง, ออกแบบ, คณะพาร์ตเนอร์, ทูตนักศึกษา |
| อาจารย์ที่ปรึกษา | 3–5 (พาร์ตไทม์) | ตรวจความถูกต้อง, ใช้ในห้องเรียน |

ถ้ามี artist แค่ 1 คน ให้ตัดกล้ามเนื้อแขนออก และเลื่อนฟันไปไตรมาสสุดท้าย

## 6. สิ่งที่ไม่ทำในปีแรก (non-goals)
อวัยวะภายใน, หลอดเลือดและเส้นประสาทแบบ 3D, กล้ามเนื้อขาและลำตัว, AR, แอป Android แบบ native (เว็บ Flutter ใช้บน Android ได้อยู่แล้ว), ภาษาเวียดนาม/อินโดนีเซีย, ฟันน้ำนม, เวอร์ชันศิลปิน
