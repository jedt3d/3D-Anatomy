# แผนพัฒนา Product ปีแรก: กระดูกและจุดสังเกต 3D ภาษาไทย

_อัปเดตล่าสุด: 2026-11-27 · สถานะ: ข้อเสนอ รอ Jedt ตัดสินใจ_

เอกสารนี้ตอบคำถามเดียว: **ใน 1 ปี ทีมเล็กที่ปั้นโมเดลและ texture เองทั้งหมด ควรทำ product ที่แคบที่สุดแบบไหน ให้จบได้จริง ขายได้ และได้ feedback จากนักศึกษาสายสุขภาพไทยตั้งแต่วันแรก**

ต่อยอดจาก [รายงานตลาด](../index.html) (ช่องว่างหลัก: แอป 3D กายวิภาครายใหญ่ไม่มีภาษาไทย) และ [ไปป์ไลน์ 3D](../3d-pipeline/index.html) (Flutter + flutter_scene, GLB, Blender เป็นศูนย์กลาง) โดยไม่ทำซ้ำ

## คำแนะนำในหน้าเดียว

| เรื่อง | ข้อเสนอ |
|---|---|
| **Niche ปีแรก** | **ระบบโครงกระดูกทั้งตัว + จุดสังเกตบนกระดูก (bony landmarks) + แผนที่จุดเกาะกล้ามเนื้อ เป็นภาษาไทย/อังกฤษ/ละติน** พร้อมโหมดฝึกสอบแบบ spot และ "เลนส์วิชาชีพ" สำหรับแพทย์ ทันตะ พยาบาล เภสัช |
| **ทำไมแคบแบบนี้** | กระดูกเป็นของแข็ง ไม่ต้อง rig ไม่ต้อง deform ปั้นเองได้เร็วที่สุดในบรรดาระบบร่างกาย และนักศึกษาทั้ง 4 วิชาชีพต้องเรียนเหมือนกันในปีแรก จุดเกาะกล้ามเนื้อทำเป็นชั้น texture บนกระดูก จึงได้เนื้อหากล้ามเนื้อโดยยังไม่ต้องปั้นกล้ามเนื้อทุกมัด |
| **ของที่ปั้นเอง** | ~120 mesh กระดูกที่ไม่ซ้ำกัน (ซ้าย/ขวาใช้ mirror) + ฟันแท้ 16 ซี่ที่ไม่ซ้ำ + กล้ามเนื้อแขน ~50 มัดเป็นของแถมปลายปี ประเมินไว้ ~400 วันทำงานของ artist 2 คน (ประมาณการ ดู [01-scope](01-scope.md)) |
| **จุดขายหลัก** | (1) ภาษาไทยที่อาจารย์ไทยตรวจแล้ว (2) ฝึกสอบ spot แบบจับเวลา (3) ใช้ offline บน iPad (4) อ่านเนื้อหาฟรีบนเว็บ (5) ราคาประมาณ 1/5 ของเจ้าใหญ่ |
| **อ่านฟรี + feedback** | ปีแรกฟรีทั้งหมด: TestFlight + เว็บ, คณะพาร์ตเนอร์ 3 แห่ง, ทูตนักศึกษา, LINE OA/OpenChat, ปุ่ม "แจ้งแก้" ทุก label, บอร์ดอาจารย์ตรวจความถูกต้อง |
| **การเปลี่ยนเป็นรายได้** | หลังเดือนที่ 12: เนื้อหาอ่านบนเว็บและ viewer กระดูกฟรีตลอด จ่ายสำหรับคลังข้อสอบ spot, แพ็ก offline, เลนส์คลินิก, โมดูลกล้ามเนื้อ และขาย license ให้คณะ |
| **ด่านตัดสิน** | เดือนที่ 1: spike flutter_scene ผ่านหรือไม่ · เดือนที่ 3: นักศึกษาใน alpha ใช้ซ้ำทุกสัปดาห์หรือไม่ · เดือนที่ 9: คณะพาร์ตเนอร์ใช้ในห้องเรียนจริงหรือไม่ |
