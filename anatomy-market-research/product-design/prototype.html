05. Prototype

Prototype อยู่ในไฟล์ Figma เดียวกับ UI กด Present (▶) ในหน้า 03, 04 หรือ 05 แล้วเลือก flow ทางซ้าย หรือเปิดลิงก์ด้านล่างโดยตรง ปุ่ม "กลับ" บนแถบนำทางทุกหน้าย้อนไปหน้าก่อนหน้า และแท็บด้านล่างสลับหน้าได้จริง

1. Flow ที่เปิดได้

Flow เริ่มที่ เส้นทางที่คลิกได้
iPad · 1 Onboarding → Home เปิด ยินดีต้อนรับ → เลือกเลนส์ → ภาษาและความยินยอม → หน้าหลัก
iPad · 2 Learn เปิด หน้าหลัก → viewer → landmarks / จุดเกาะ / จุดคลินิก → แจ้งแก้ · คลัง → ค้นหา → landmark · การ์ดกะโหลก → FDI
iPad · 3 Spot exam เปิด ตั้งค่า → คำถาม → เฉลย → ผลสอบ → ทบทวนข้อผิด / สอบใหม่ · เฉลย → แจ้งแก้ · ตั้งค่า → โหมดอาจารย์
iPad · 4 Me เปิด ฉัน → รายการที่ฉันแจ้ง · ฉัน → ข้อมูล offline → ดาวน์โหลด → alert ยืนยัน
มือถือ · Daily review เปิด ทบทวนวันนี้ → การ์ดหน้า → เฉลย → ให้คะแนน → การ์ดถัดไป
มือถือ · Quick lookup เปิด ค้นหา → รายละเอียดศัพท์
เว็บ เปิด ดัชนี → หน้าอ่าน Femur → viewer 3D บนเว็บ → กลับหน้าอ่าน

ทั้งหมด 104 จุดที่คลิกได้ ใช้ Smart animate 300 ms สำหรับการไปหน้าถัดไป และ dissolve 200 ms สำหรับ sheet, alert และการสลับแท็บ
